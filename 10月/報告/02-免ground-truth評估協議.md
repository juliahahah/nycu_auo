## 一、為什麼要繞過 ground truth

論文的做法是：本人答 177 題 GSS + 44 題 BFI + 5 個賽局，**兩週後再答一次**，用本人前後一致性當滿分基準。
這對一位教授不可行：兩次施測至少各 90 分鐘，而且教授一旦看過題目，第二次作答就不獨立了。

教授 9/19 提的替代方案：
1. 先把 role data 蒸餾成分身（女媧流程 + 教授自述）。
2. 再設計**不需要本人逐題答案**也能判斷像不像的任務。

判斷的來源從「跟本人答案逐題比對」換成三種：
- **既定規則**：任務本身有計分規則（DISC、BFI-44），結果合不合理不需要本人在場。
- **專家直覺**：本人或熟識者看產出，判斷「這像不像我／他會做的」。
- **天然對照組**：對象本來就有公開產出（真實課綱、真實投影片），直接比。

## 二、協議全文

### 第 0 步：凍結分身
- 分身版本、蒸餾用的資料清單、base model 名稱與版本，全部記錄；評估期間不得再改。
- 評估題目在蒸餾**之後**才出，出題人不看蒸餾用的資料。

### 第 1 步：任務一 ── 標準化量表（有既定規則）
| 項目 | 內容 |
|---|---|
| 工具 | BFI-44（繁中版）；DISC 視授權結果決定 |
| 作答方 | 分身（同一題三次獨立作答，取多數；看穩定度） |
| 比對方 | (a) 本人自評一次 (b) 2–3 位熟識者對本人的他評 |
| 指標 | 五個向度的分身分數與本人自評／他評的相關與差距；分身三次作答的內部一致性 |
| 通過標準（暫定） | 五向度中至少 4 個，分身與本人差距 ≤ 0.5（五點量表）；分身三次作答變異小於本人與他評的差距 |
| 這步在測什麼 | 女媧原本沒有的「個體差異座標」——補心理學的第一塊 |

### 第 2 步：任務二 ── 開放生成任務（專家直覺）
題目：「假設你要開一門〈X〉，請設計 12 週的課程框架，並說明為什麼這樣排。」

| 項目 | 內容 |
|---|---|
| 題目數 | 3 門課：一門本人教過（有真實課綱可比）、一門本人沒教過但在專長內、一門專長外 |
| 產出 | 每門課：週次主題 + 排序理由 + 作業設計 + 三句給學生的話 |
| 評分者 | 本人 1 位 + 熟識者 2 位 + 不認識本人的同領域教授 2 位 |
| 盲測設計 | 每門課給評分者 3 份課綱：分身生成、另一位教授的分身生成、真人（本人或他人）寫的。評分者不知道哪份是誰的 |
| 評分項 | (1) 辨認：哪一份是這位教授的？ (2) 像不像 1–5 (3) 哪裡最像／最不像（開放） |
| 指標 | 辨認正確率（隨機 = 33%）；像不像平均分；真人評分者間一致性（Cohen's κ 或 ICC） |
| 通過標準（暫定） | 熟識者辨認率 > 67%；不認識者辨認率不顯著高於 33%（代表像的是「這個人」而非「這種教授」） |
| 這步在測什麼 | 推理程序像不像——女媧原本就擅長的那層，但用真人評分者取代 agent 評分者 |

**為什麼加「不認識本人的教授」**：如果連不認識的人都能猜對，代表分身靠的是刻板印象（例如「電機系教授都會這樣排課」），不是個人特徵。這是我們版本的「人口統計對照組」。

### 第 3 步：任務三 ── 待與教授確認（D4 候選）
原筆記寫到「3.」就斷了。以下四個候選都符合「不需本人 ground truth」：

| 候選 | 做法 | 判斷來源 | 優點 | 缺點 |
|---|---|---|---|---|
| **3a. 學生問答重演** | 拿過去學生真的問過教授的 10–20 個問題（信件、meeting 紀錄），讓分身回答；本人看 | 專家直覺 + 天然對照（教授當年真的怎麼回） | 最貼近應用場景；有真實答案可對照，卻不用重測 | 需要教授願意提供舊信件 |
| **3b. 審稿任務** | 給分身一篇論文摘要，請它寫審稿意見；跟本人實際審過的意見比 | 天然對照 | 研究品味最直接的展現 | 審稿意見有保密問題 |
| **3c. 立場預測（女媧原生）** | 對本人公開反覆表態過的 5 題，分身回答方向對不對 | 既定事實 | 最便宜，女媧評分卡已有 | 只測公開立場，測不到私下的判斷 |
| **3d. 第三方盲辨** | 把分身與本人各自回答同一組問題，讓學生猜哪個是真人 | 專家直覺（圖靈測試式） | 直觀、好講 | 本人要參與答題，成本回升 |

初步建議 **3a**：它跟第一階段的應用（回答學生問題）是同一件事，等於把驗證直接做在產品上。

### 第 4 步：女媧評分卡（沿用但補強）
- 照 `fidelity-scorecard.md` 五維度跑，答題與評分兩個獨立 agent。
- **補強一**：評分 agent 用兩個不同模型家族各跑一次，報分差；分差 > 10 人工複核（官方 15 例全用同一家模型評，這是我們的改進）。
- **補強二**：立場一致性題目由真人也評一次，算 agent 與真人的 κ。
- 產出 FIDELITY.md 放進 skill 目錄。

### 第 5 步：報告格式
一頁表：任務／指標／分身得分／基準線（其他教授分身、隨機、真人）／通過與否。
不通過的項目照實寫，並註明是資料不足、蒸餾流程問題、還是任務本身超出分身能力（例如行為層）。

## 三、代價：沒有 ground truth 會被怎麼打（D5）

| 審稿人會說 | 我們的回答 | 還做不到的部分 |
|---|---|---|
| 「你們沒有本人重測，怎麼知道分身的誤差是分身的問題還是人本來就不穩？」 | 我們不宣稱 normalized accuracy；我們報絕對一致率，並用「其他教授的分身」和「不認識本人的評分者」當基準線，測的是「像這個人」而非「像這類人」 | 沒有本人重測就無法回答「人有多穩」；這點只能引用論文（GSS 本人重測 79.5%） |
| 「專家直覺不客觀。」 | 評分者盲測、多人、算 κ；並加入不認識本人的評分者當對照 | 樣本仍小（5 位評分者），統計力有限 |
| 「n = 1，沒有外推性。」 | 第一階段目標是驗證**方法**（協議能不能區辨像／不像），不是驗證**母體**；第二位對象（例如李宏毅）用來檢查協議是否重現 | 要到第二位對象跑完才算回應 |
| 「態度層準有什麼用？決策才重要。」 | 直接承認：行為層論文自己都失敗（0.03–0.11），我們不承諾；應用場景（回答學生問題）落在態度層 | 行為層是開放問題，我們現在沒有解 |
| 「題目是你們自己出的，可能偏向分身會答對的方向。」 | 出題人與蒸餾人分開；出題在蒸餾之後；任務二用真實課綱當對照，不是自己出的 | 態度題庫 v0.1 初稿仍是我們寫的，需第三方審題 |

## 四、時程估計（第一階段，一位教授）

| 步驟 | 需要教授本人的時間 | 需要我們的時間 |
|---|---|---|
| 自述訪談（改寫版 AVP） | 60–90 分鐘一次 | 改寫腳本 1 週；訪談整理 1 週 |
| 蒸餾 | 0 | 1–2 週（含公開資料整理） |
| 任務一 BFI-44 自評 | 10 分鐘 | 他評聯絡 1 週 |
| 任務二 課程框架評分 | 30 分鐘 | 出題、盲測包裝、聯絡評分者 2 週 |
| 任務三 3a 舊問答 | 提供素材 + 30 分鐘看結果 | 1 週 |
| 評分卡 | 0 | 2 天 |
| **合計** | **約 3 小時** | **約 6–8 週** |

跟論文的「兩小時訪談 + 兩次施測各 90 分鐘」比，教授的時間從 5 小時降到 3 小時，而且沒有重測的獨立性問題。
