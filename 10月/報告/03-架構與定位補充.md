## 二、B″3：評分者間信度怎麼補

女媧評分卡的評分者是一個 agent，而且與答題 agent 同一模型家族。心理計量學對此的標準處理：

1. **多評分者**：至少 2 位獨立評分者，報一致性。
2. **異源評分者**：評分 agent 用不同模型家族；再加真人評分者。
3. **一致性指標**：
   - 類別判定（例如「立場方向對／偏／錯」）→ Cohen's κ（兩位）或 Fleiss' κ（多位）。
   - 連續分數（例如風格辨識度 0–20）→ ICC（組內相關）。
   - 經驗門檻：κ ≥ 0.6 算實質一致，≥ 0.8 算高度一致。
4. **分歧處理**：分差 > 10 分人工複核（女媧已有此規則，但沒說複核結果怎麼記）。我們的做法：複核結果與原始兩份評分一起保留，不覆寫。

這次自家 demo 的評分就照這個做：兩個評分 agent（不同模型），並記錄分差。

## 三、C1：多視角顧問團架構（文字版，圖在投影片）

```
                 ┌─────────────┐
   同一個問題 ──►│  路由／分派  │
                 └──────┬──────┘
          ┌─────────────┼─────────────┐
          ▼             ▼             ▼
    ┌───────────┐ ┌───────────┐ ┌───────────┐
    │ 分身 A     │ │ 分身 B     │ │ 分身 C     │   ← 每個都是一份蒸餾 skill
    │（教授甲）  │ │（教授乙）  │ │（吳恩達）  │      + 各自的資料來源標記
    └─────┬─────┘ └─────┬─────┘ └─────┬─────┘
          ▼             ▼             ▼
                 ┌─────────────┐
                 │  彙整層      │  ← 不做「平均」，做「列出分歧點」
                 │ 共識／分歧／ │     每個意見附來源顏色（綠／黃／紅）
                 │ 各自理由     │
                 └─────────────┘
```

設計要點：
- **彙整層不投票**。顧問團的價值是看到不同框架怎麼看同一題，把意見平均掉就沒了。
- **每個分身標記 base model**。這樣才能事後分析：分歧是來自人格資料，還是來自模型（見 C3 實驗）。
- **來源顏色沿用 goal.md 4.3**：綠 = 本人講過、黃 = 模型補的、紅 = 推測。

## 四、C2／C3：base model 要不要不同——兩種讀法先寫好

教授原話：「背後語言模型都不一樣？這樣比較標準？可以得到更不一樣的結果？」兩種解讀：

| 讀法 | 目的 | 做法 | 風險 |
|---|---|---|---|
| **控制變因** | 確認分身之間的差異來自人格資料，不是同一個模型的腔調 | 同一份資料跑多個模型，看差異多大（= C3 實驗） | 若模型間差異很大，代表分身的「個性」有一部分其實是模型的 |
| **增加多樣性** | 顧問團的意見更不一樣 | 不同分身故意配不同模型 | 多一個變因；模型能力有落差，不公平 |

我們的建議：**先當控制變因來測**（C3），量到差異多大再決定顧問團要不要混模型。若同一資料跨模型差異小，就可以放心混；若差異大，顧問團裡所有分身應該固定同一模型，模型差異另外報。

C3 實驗設計（已執行，結果待回填）：同一份吳恩達 skill、同 2 題、3 個模型（Haiku 4.5 / Sonnet 5 / Opus 5），比較立場方向是否一致、關鍵詞是否重疊、風格差在哪。

## 五、C4：「個人顧問」定位對架構的額外需求

「像不像」跟「能不能當顧問用」是兩件事。顧問要的是：

| 需求 | 擬真分身不一定有 | 架構上怎麼補 |
|---|---|---|
| **可靠**：同一題問三次答案方向一致 | 生成有隨機性 | 任務一已加「同題三次作答」；顧問模式下溫度調低、或三次取多數 |
| **一致**：不跟自己十分鐘前講的矛盾 | 沒有記憶時容易 | 對話內保留立場摘要；跨對話用 skill 內的「核心張力」段落明示哪些是本人自己也沒定論的 |
| **會拒答**：超出本人談過的範圍要說 | 女媧有「邊緣誠實度」維度，這點反而是它的強項 | 沿用；加上 goal.md 的紅色標記 |
| **可追溯**：說的每句話能指回來源 | 女媧有「來源透明度」但只在 skill 檔案層，不在回答層 | 回答層加來源顏色（綠／黃／紅） |
| **不越界**：不替本人做承諾（收學生、給成績） | 擬真反而會越界 | 拒答政策：行為層問題一律轉「這要問本人」 |

結論：**顧問定位不改變蒸餾流程，但改變回答層的規則**——加穩定性、加來源標記、加行為層拒答。這三條可以直接寫進 skill 的「角色扮演規則」。
